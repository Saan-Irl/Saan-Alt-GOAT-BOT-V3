🧪 𝐌𝐀𝐊𝐄 𝐘𝐎𝐔𝐑 𝐎𝐖𝐍 𝐂𝐎𝐌𝐌𝐀𝐍𝐃

Example:

module.exports = {
  config: {
    name: "hello",
    version: "1.0",
    author: "𝐒𝐈𝐀𝐌 𝐀𝐇𝐌𝐄𝐃 𝐒𝐀𝐀𝐍",
    countDown: 5,
    role: 0,
    description: {
      en: "Say hello"
    },
    category: "fun",
    guide: {
      en: "{pn}"
    }
  },

  langs: {
    en: {
      reply: "Yo %1, what's good?"
    }
  },

  onStart: async function ({ args, message, getLang }) {
    return message.reply(
      getLang("reply", args[0] || "bro")
    );
  }
};

🧯 𝐂𝐎𝐌𝐌𝐎𝐍 𝐏𝐑𝐎𝐁𝐋𝐄𝐌𝐒

Node.js error

Check:

node -v

The intended runtime for this build is:

Node.js 22.x

Dependency error

Try:

rm -rf node_modules
npm install

Then:

npm start

Database error

Check:

- MongoDB URI
- Database configuration
- Network access
- Required environment variables

Login / session error

Verify your Messenger session/account configuration and avoid repeatedly attempting login with invalid credentials.
